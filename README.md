# سلسبيل (Salsabil) — ديوان

> نقطة الدخول الوحيدة لأي إنسان أو أداة ذكاء اصطناعي تفتح هذا المستودع لأول مرة. لا تبدأ بقراءة
> الكود مباشرة — ابدأ من هنا.

**سلسبيل** محاولة لبناء نظام تشغيل حضاري عربي-إسلامي الهوية، يبدأ بمنتج تجاري بسيط (**ريف
المدينة**) وينمو تدريجياً تحت مظلة واحدة اسمها **ديوان**. الرؤية الكاملة، الفلسفة، وتاريخ القرارات
المعمارية موجودة في `SALSABIL_CONSTITUTION.md` — لا تُختصَر هنا.

---

## ابدأ هنا (بالترتيب، بلا تخطي)

1. **[`SALSABIL_CONSTITUTION.md`](SALSABIL_CONSTITUTION.md)** — الرؤية، المبادئ الحضارية والمعمارية العليا غير القابلة للكسر.
2. **[`AGENTS.md`](AGENTS.md)** — بروتوكول العمل الإلزامي. **لا يُنفَّذ أي كود جديد قبل قراءة هذا الملف كاملاً** — هو الذي يحدد كيف تُنفَّذ أي مهمة (STOP → READ → SEARCH → PLAN → IMPLEMENT → VERIFY → REPORT).
3. **[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)** — كيف تُطبَّق المعمارية تقنياً اليوم: الطبقات، حدود كل نطاق (Domain)، اتجاه الاعتماد المفروض آلياً.
4. **[`docs/ROADMAP.md`](docs/ROADMAP.md)** — أين نحن بالضبط الآن (تتبّع حي يوماً بيوم لكل ما بُني فعلياً).

**بعد هذه الأربعة، عند الحاجة الفعلية:**
- `INVARIANTS.md` — سجل الثوابت الملزمة (أمان/اتساق بيانات) وحالتها الحقيقية القابلة للتحقق.
- `docs/DECISIONS.md` — كل قرار معماري (ADR) ولماذا اتُّخذ، بما فيها القرارات المعلَّقة (Decision Debt) وسجل التعارضات.
- `docs/DOCUMENTATION_RULES.md` — كيف تُقرأ وتُحدَّث بقية الوثائق (مستويات الدليل، من يقرر ماذا).

## الحالة الحالية بإيجاز شديد

Backend Vertical Slice (ريف المدينة: عميل + تاجر + إدارة) مكتمل وحيّ على `staging.reefam.com` +
Context Engine (خليل، عوالم/شخصيات) مكتمل بنطاق ضيق (عالم واحد) + بيان (محرك محتوى ريف، الأيام
23-32) قيد البناء — راجع `docs/ROADMAP.md` للتفصيل الدقيق يوماً بيوم، ولملاحظات الدقة الصريحة حول
معنى "حيّ" هناك.

> ⚠️ **قبل أي عمل على تسجيل الدخول/الصلاحيات:** تسجيل دخول التاجر والإدارة اليوم بالهاتف وحده بلا
> كلمة مرور — `BLOCKER` صريح موثَّق (`docs/SECURITY.md §1`, `DD-001` في `docs/DECISIONS.md`) يمنع
> تسجيل أي تاجر/حساب إدارة ثانٍ حقيقي قبل إغلاقه.

## تشغيل المشروع محلياً

```bash
npm install
cp .env.example .env.local   # ثم املأ القيم الثلاث من Supabase Project Settings → API
npm run dev
```

متطلبات `.env.local` كاملة وموثَّقة داخل [`.env.example`](.env.example) — لا تُنسَخ هنا لتجنّب
انحراف نسختين عن بعضهما.

أوامر مفيدة أخرى (من `package.json`):
```bash
npm run typecheck   # فحص أنواع TypeScript
npm run arch:check  # فحص حدود المعمارية (dependency-cruiser) — راجع docs/ARCHITECTURE.md §3.1
npm run test:unit   # اختبارات الوحدة (سريعة، بلا شبكة)
npm run test        # كل الاختبارات، بما فيها التكامل الحي ضد Supabase
```
