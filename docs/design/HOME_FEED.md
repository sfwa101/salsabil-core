# بنية الصفحة الرئيسية — Home Feed

## 1. المبدأ: Feed لا نهائي (Discover → Engage → Convert)

الصفحة الرئيسية لريف المدينة **خلاصة (Feed) لا نهائية**، لا صفحة كتالوج ثابتة. الرحلة المقصودة:

```
Discover (تصفّح المحتوى) → Engage (فتح منشور/ريل/وصفة) → Convert (إضافة منتج مرتبط للسلة)
```

**التنفيذ الفعلي القائم** (`src/components/Feed.tsx`، `IntersectionObserver`): تحميل مستمر بالتمرير،
لا ترقيم صفحات (Pagination) تقليدي. هذا مطابق للمبدأ ولا يتغيّر في هذه الدفعة.

## 2. المسافة اكتشاف↔شراء قصيرة جداً

من أي منشور/ريل يحمل رابط منتج (`post_media.link.type === 'product'`) إلى شراء فعلي: نقرة واحدة تفتح
`BottomSheet` (منتج أو وصفة)، وزر "أضف للسلة" داخل نفس الـ`Sheet` — بلا تنقّل لصفحة منفصلة. هذا
مُنفَّذ فعلاً (`RecipeSheetContent.tsx`/Product Sheet، اليوم 28) ولا يتغيّر في هذه الدفعة؛ يُذكر هنا
فقط كقيد تصميمي يُقاس عليه أي عنصر جديد مستقبلاً: أي إضافة تُبعِد الشراء عن الاكتشاف بخطوة إضافية
غير ضرورية تخالف هذا المبدأ.

## 3. ليس كل منشور CTA شرائي

`PostMediaLink` (راجع `CONTENT_MODEL.md`) نوع اتحادي صريح: `NoLink | ProductLink | RecipeLink`. صورة
منشور بلا رابط منتج (`{ type: 'none' }`) محتوى تحريري بحت — لا زر شراء مفروض عليها. هذا تصميم قائم
فعلياً في `bayan/types.ts` منذ اليوم 23، يُوثَّق هنا كمبدأ صريح لا يُنتهَك عند إضافة أنواع محتوى
جديدة مستقبلاً (`CONTENT_MODEL.md §3`).

## 4. البنية الفعلية للصفحة (بعد هذه الدفعة)

```
┌─────────────────────────────────────────┐
│ Header (layout.tsx، ثابت عبر كل صفحات reef) │
│  ├─ صف 1: [مبدّل العوالم] [العنوان+التوصيل] [كبسولة السلة] │
│  └─ صف 2: شريط بحث (ملتصق بلا فراغ)        │
├─────────────────────────────────────────┤
│ ScrollHideBar (يختفي/يظهر معاً بالتمرير)   │
│  ├─ StoryBar (الأحياء، حلقات متدرّجة)      │
│  └─ FeedTabBar (الكل | ريلز | منتجات | منشورات) │
├─────────────────────────────────────────┤
│ Feed (تمرير لانهائي — PostCard × N)        │
├─────────────────────────────────────────┤
│ BottomNav (عائم، layout.tsx)               │
└─────────────────────────────────────────┘
```

`FeedTopBar.tsx` (كان يحمل مبدّل العوالم + عنوان التوصيل + زر باركود + زر بحث موبايل) **حُذف** في
هذه الدفعة — مسؤولياته الحقيقية (عالم + عنوان) انتقلت إلى `Header.tsx`، راجع `COMPONENTS.md`.
