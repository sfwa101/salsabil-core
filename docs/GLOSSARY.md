# قاموس المصطلحات

> **ملاحظة:** هذا المحتوى موجود أيضاً في `SALSABIL_CONSTITUTION.md §37`. لم يُحذف من الدستور (القاعدة الصارمة: لا تعديل الدستور في هذه المرحلة). هذا الملف نسخة مستقلة قابلة للتحديث بمصطلحات جديدة دون انتظار تحديث الدستور، وسيُقتَرح حذف §37 من الدستور نفسه ضمن `PROPOSED_CONSTITUTION_CHANGE.md`.

| المصطلح | المعنى |
|---|---|
| Vertical Slice (قطعة رأسية) | رحلة مستخدم كاملة تعمل من قاعدة البيانات حتى الواجهة، بدل شاشات متفرقة غير مكتملة |
| Multi-Tenant | نظام واحد يخدم عدة "مستأجرين" (تجار) مع عزل كامل لبيانات كل واحد |
| RLS | Row-Level Security — التحكم بالوصول على مستوى كل صف في قاعدة البيانات |
| RBAC/ABAC | أنظمة التحكم بالصلاحيات حسب الدور أو الخصائص |
| Adapter | طبقة وسيطة تعزل منطق العمل الأساسي عن أي خدمة خارجية |
| Stem Cell Architecture | لا شيء ثابت (Hardcoded)، كل شيء قابل للتهيئة من سجل مركزي |
| Vertical مقابل Horizontal في التوسع | عمودي = تعميق ميزة واحدة حتى تعمل بالكامل؛ أفقي = ميزات كثيرة سطحية غير مكتملة |
| GMV | Gross Merchandise Value — إجمالي قيمة التداول عبر المنصة |
| Webhook | استدعاء تلقائي لخدمة خارجية عند حدوث معين |
| BEAM / OTP | منصة تشغيل Erlang/Elixir؛ عزل عمليات، أشجار إشراف، انتعاش ذاتي |
| Supervision Tree | عملية "مُشرِف" تعيد تشغيل عمليات معطوبة دون التأثير على الباقي |
| Actor Model | كل وحدة معزولة تماماً، تواصل عبر رسائل فقط |
| وقف (Waqf) | نموذج حوكمة إسلامي، كيان غير مملوك لأحد، يُدار لغرضه الدائم |
| Fair Matching Engine | محرك نقاط مرجّح يوازن العدالة (الدور) والكفاءة (القرب/السعر) |
| Unified Inbox | واجهة واحدة تجمع محادثات من منصات متعددة |
| Stem Cell UI | نفس التطبيق والبيانات، تبديل كامل لطريقة العرض دون تغيير المنطق |
| Cold Start | لا بيانات كافية للتخصيص في البداية؛ الحل: قواعد بسيطة أولاً، تعلّم تراكمي لاحقاً |
| Landed Cost | التكلفة الكاملة لمنتج مستورد حتى الباب (سعر + شحن + جمارك + ضرائب) — مصطلح من محادثة الاستيراد الدولي، خارج الدستور v1.2 |
| Risk Transfer | تحويل مخاطرة التحقق من آلاف الموردين إلى جهة وسيطة واحدة موثوقة مسؤولة تعاقدياً |
| Evidence Level | تصنيف إلزامي لكل معلومة (CONSTITUTION/IMPLEMENTED/PROPOSED/...) — راجع docs/DOCUMENTATION_RULES.md §3 |
