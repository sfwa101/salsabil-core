# الأفكار المؤرشفة

لا توجد حتى الآن أي فكرة رُفضت رسمياً عبر كل محادثات بناء سلسبيل — كل ما نوقش إما اعتُمد (`ACCEPTED`)، أُجِّل (`DEFERRED`)، أو لا يزال قيد التقييم (`EVALUATING`) في `ideas/IDEAS.md`.

هذا الملف يبقى فارغاً بصدق حتى تُرفض فكرة فعلياً — **لا يُخترع محتوى لملء هذا الملف.**

عند رفض أي فكرة مستقبلاً، تُنقَل هنا بنفس قالب IDEAS.md مع إضافة:
```
Rejected Date:
Rejected Reason:
```
